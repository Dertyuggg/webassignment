# Design a Shopping Mall website using HTML frames with 3 sections as shown.

Create a webpage using 3 frames:
Header, Navigation (Directory), and Content
Use <frameset> and <frame> tags to divide the page
Design a header frame with mall name and tagline
Create a left-side navigation menu with links:
Home, Fashion & Apparel, Food Court, Cinema, Contact Us
Display content in the right-side frame when links are clicked (use target attribute)
Apply basic CSS styling (background color, text alignment, fonts)
Maintain layout similar to the given design
